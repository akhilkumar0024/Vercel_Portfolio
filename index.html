Product & EdTech Prototype

Nipp-On

View Source on GitHub north_east

An AI-assisted Japanese vocabulary learning and conversation practice application focused on JLPT N5 learners, combining vocabulary breakdowns, conversational tutoring, quizzes, browser-based speech capabilities, and a persistent vocabulary notebook.

Goals & Learning Flow

Addresses the steep learning curve beginner JLPT N5 learners face with kana and vocabulary retention through guided conversational prompts, interactive quizzes, and persistent progress logging.

UX Decisions & AI Integration

Integrates Google Gemini API for conversational tutoring and contextual feedback. Uses structured curated vocabulary sets as reliable foundational content alongside client speech synthesis.

Implementation Note & Current Scope

Speech synthesis and recognition rely on native browser Web Speech API engines, which vary according to operating system language pack support and client microphone clarity. Uses localStorage for the persistent vocabulary notebook.

Simulated AWS IoT & Cloud Infrastructure

Smart Helmet SIM

View Source on GitHub north_east

A simulated AWS IoT telemetry and emergency-response infrastructure project exploring event-driven processing, crash-anomaly validation, rider override workflows, emergency notification logic, and decoupled cloud infrastructure.

1. Telemetry Ingestion

Simulated sensor client emits sensor impact payloads via MQTT over TLS into AWS IoT Core topic rules.

2. Event Processing & Anomaly

Amazon SQS buffers incoming messages; containerized workers in ECS Fargate validate anomalous thresholds against DynamoDB.

3. Override & Notification Flow

AWS Step Functions manages the rider override timeout window; dispatches emergency notifications via SES and operational alerts via SNS.

Simulation Context & Alert Architecture

A software simulation exploring telemetry and decoupled cloud workflows, not physical or automotive-certified hardware. Amazon SNS handles operational alerts and CloudWatch alarms (DLQ, DynamoDB throttling, Step Functions failures), while Amazon SES delivers direct emergency notification emails.
